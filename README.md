# Python-Slot-Machine-Game
A simple command-line slot machine game built using Python.

## Features

- Deposit money to start playing
- Choose betting lines (1–3)
- Set bet amount per line
- Random slot machine spins
- Winning calculation based on matching symbols
- Balance tracking and input validation

## Tech Stack

- Python 3
- `random` module
## Game Rules

- Select number of betting lines (1–3)
- Choose bet amount per line
- Total Bet = `bet × lines`
- Match symbols across a line to win.

## Learning Concepts

- Functions
- Loops & Conditionals
- Dictionaries
- Randomness
- Input Validation
- Modular Programming
